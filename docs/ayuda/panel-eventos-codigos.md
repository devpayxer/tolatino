# Panel › Eventos: códigos de descuento · Dashboard › Events: discount codes

_Pantallas: **Panel › Eventos › tu evento › CÓDIGOS DE DESCUENTO**. Teléfono y escritorio. Versión: 10 nov 2026. Audiencia: negocio. Tema: panel._

## Qué hace
- **Crear código**: el código (3 a 16 letras o números, p. ej. AMIGOS10), **Porcentaje** (5 % a 90 %) o **Monto fijo** ($1 a $500) y
  cuántos **usos**. Cada código sale con **N de M usos** y un interruptor para apagarlo o encenderlo.
- **El descuento sale de lo tuyo**: baja el precio de los boletos, no la comisión de To'Latino. Vale para boletos (no para la mesa ni los
  extras) y nunca deja un boleto en menos de $2.
- El cliente lo escribe en **¿Tienes un código?** y ve **CÓDIGO APLICADO · −$X**.

## Qué pasa en cada caso
| Caso | Qué pasa |
|---|---|
| Se acabaron los usos | El cliente ve «Ese código ya se usó todas las veces.» |
| Alguien en pleno pago con el código | Cuenta como apartado («N en un pago»); si no paga, el uso vuelve. |
| La misma persona lo intenta dos veces | «Ya usaste ese código en este evento.» Un uso por persona y evento. |
| Alguien prueba códigos al azar | Después de varios intentos que no existen, tiene que esperar. |
| Apagas el código | Deja de aplicarse desde ese momento; lo ya vendido no cambia. |
| Ya tienes ese código | «Ya tienes ese código en este evento.» |

## Preguntas frecuentes
- **¿To'Latino tiene sus propios códigos?** No: solo los del organizador.
- **¿Puedo borrar un código?** Se apaga (nada se borra; queda el historial de usos).

## English

### What it does
**Create code**: 3–16 letters or numbers, **Percent** (5–90%) or **Fixed amount** ($1–$500) and how many **uses**; each code shows **N of M
uses** and an on/off switch. **The discount comes out of your share**: it lowers ticket prices, not To'Latino's fee; tickets only, never below
$2. Customers type it in **Have a code?** and see **CODE APPLIED · −$X**. Used up → "That code has been used up." One use per person per event.
Random guessing is rate limited. Turning a code off stops it from then on. Codes are never deleted, only turned off.
