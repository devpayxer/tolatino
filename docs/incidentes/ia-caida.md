# Proveedor de IA caído

_Manual interno de incidentes (9o; fase9-apertura.md §3.4). No es ayuda de El Compa: es para el equipo y para Claude. Cada caso: cómo se nota → qué hace el sistema solo → qué hace Claude → qué se le dice al fundador y a los vecinos. Lo que cada caso abre queda en `incident_log` (Super Admin › Sistema › Despliegues) con este archivo como `manual_ref`._

**Severidad:** media · **caso:** `ia-caida`

## Cómo se nota
- El Compa contesta con error; sube «El Compa no responde».

## Qué hace el sistema solo
- El Compa pasa a «Con una persona» (decisión F): el caso va a Soporte con su conversación; las respuestas automáticas Pro se pausan.

## Qué hace Claude
- Confirmar el estado del proveedor; nada que reiniciar del lado nuestro.

## Qué se le dice al fundador
- «El Compa no contestó N minutos; N conversaciones pasaron a una persona.»

## Qué se les dice a los vecinos
- En la hoja de El Compa: la línea de siempre que lo pasa a una persona.
