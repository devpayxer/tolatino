# To'Latino

Plataforma *all in one* para latinos en Estados Unidos, por ciudad (piloto:
Hazleton, PA): Negocios · Comunidad · Eventos.

**Estado (5 nov 2026): planificación de la v2.** Reinicio desde cero con nuevo
diseño y nueva estrategia.

- `docs/PLAN.md` — plan de construcción (borrador para aprobar).
- `docs/diseno/` — documentación del diseño copiada del proyecto de Claude
  Design (plan, taxonomía, modelo de datos, sistema de diseño).
- `CLAUDE.md` — memoria del proyecto para Claude Code.

El código v1 (lo que corre hoy en tolatino.com) está archivado en las ramas
`archivo/v1-produccion` y `archivo/v1-pruebas`.
